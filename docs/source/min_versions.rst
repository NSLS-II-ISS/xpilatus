Supported versions
==================

The package requires Python 3.11 or newer, NumPy 1.26 or newer, and PyQt5 5.15.
Exact dependency ranges are maintained in ``pyproject.toml``. The reproducible
Pixi environment uses Python 3.12 on Linux x86-64; pip CI also checks Python 3.11
and 3.13. PyQt5 is retained for compatibility with existing host applications.
